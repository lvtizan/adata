# 3.仓位的动态调节：油⻔与刹⻋

核⼼观点：仓位不是固定的，⽽是根据账⼾盈亏和市场波动实时调节的。

⽼冯原话： “上涨时⼤仓位在⾼波动，下跌时⼤仓位在低波动” 。

操作细节：

⼤盘⽆⻛险时：收盘保持 $5 0 \% - 7 0 \%$ 仓位，盘中进⾏买卖。

0 应对回撤时：如果账⼾⼤涨触发⽌盈，很多个股清仓或减半；如果第⼆天低开，因为仓位 轻，⼼态会很有优势。
