# 股票分析系统 UI 规范文档（TradingView 风格 / AI 执行版）

## 1. 文档目标

为本项目建立一套统一、可扩展、可复用的全局 UI 规范。
该规范用于指导 AI 完成以下工作：

- 搭建整站统一视觉风格
- 统一页面布局与组件规则
- 统一图表页、表格页、复盘页、选股页的设计语言
- 避免不同页面风格割裂
- 确保系统长期迭代时仍保持专业、一致、克制的金融终端感

本规范参考 TradingView 网页端的设计思路，但不是照搬。目标是吸收其核心优势：

- 图表优先
- 高密度但有秩序
- 工具栏位置稳定
- 专业、克制、低干扰
- 适合长时间使用
- 强调工作台属性，不走资讯站或营销页风格

## 2. 产品定位与视觉目标

### 2.1 产品定位

这是一个股票分析 / 复盘 / 选股 / 观察系统。
用户核心行为不是浏览内容，而是：

- 看图
- 对比板块与个股
- 快速切换标的
- 观察列表
- 复盘交易
- 查找主线与强弱关系
- 记录和验证交易逻辑

因此 UI 必须优先服务"分析工作流"，而不是内容阅读。

### 2.2 整体视觉气质

- 专业
- 克制
- 冷静
- 高密度
- 低噪音
- 数据优先
- 图表优先
- 金融终端感
- 不花哨
- 不营销化

### 2.3 设计关键词

AI 在实现界面时，必须始终遵守以下关键词：

Professional, Minimal, Dense but structured, Chart-first, Tool-oriented, Neutral, Focused, Consistent, Clear hierarchy, Low decoration

## 3. 设计原则

### 3.1 图表优先

图表是系统的核心。任何页面只要包含图表，就必须让图表成为视觉中心。不能让卡片、说明文字、按钮组、筛选模块抢走主图的权重。

### 3.2 主任务优先

每个页面都必须有一个明确的"主任务区域"。页面不能所有模块都差不多大，否则会导致视觉中心缺失。必须一眼看出当前页面的核心模块是什么。

### 3.3 高频操作位置固定

高频操作的位置必须稳定，例如：搜索、周期切换、指标入口、右侧自选、左侧工具、顶部操作栏。不要在不同页面随意挪动核心操作位置。

### 3.4 高密度但不拥挤

页面可以承载较多数据，但必须通过以下方法维持秩序：严格对齐、统一间距、明确分区、统一字号、控制颜色数量、控制边框强度、避免无意义卡片化。

### 3.5 低干扰

避免以下设计倾向：大面积高饱和背景、炫光发光效果、夸张阴影、大量渐变、大圆角胶囊、花哨插画、多个主按钮抢焦点、多层复杂背景纹理。

### 3.6 稳定一致

同一类模块必须长得像同一类模块。所有表格风格一致、所有侧栏风格一致、所有按钮风格一致、所有标题层级一致、所有弹层行为一致。

## 4. 全局布局规范

### 4.1 整站布局模型

统一采用五区结构：

- Top Bar 顶部全局栏
- Left Rail 左侧工具栏
- Main Workspace 中央主工作区
- Right Panel 右侧信息面板
- Bottom Context Bar 底部上下文栏（按需显示）

### 4.2 顶部全局栏 Top Bar

- 高度：48px
- 左右内边距：16px
- 内部按钮高度：32px
- 按钮间距：8px
- 模块组间距：12px 或 16px

可包含：页面标题、当前视图名称、股票/板块搜索、周期切换、指标按钮、布局切换、收藏/自选、更多操作、用户菜单、系统设置

不可包含：大段说明文字、多行筛选器堆叠、冗长统计说明、大尺寸营销卡片、多层嵌套模块

### 4.3 左侧工具栏 Left Rail

- 宽度：52px
- 单个工具热区：36x36px
- 工具间距：8px
- 上下内边距：8px

单列垂直排布、图标优先、默认只展示图标、hover 显示 tooltip、当前激活工具状态明确。

### 4.4 中央主工作区 Main Workspace

承载页面主任务。中央工作区必须是整个页面最大区域。有清晰的模块边界。不允许被过多辅助信息切碎。当页面有图表时，图表必须占最大面积。

### 4.5 右侧信息面板 Right Panel

- 默认宽度：320px
- 最小宽度：280px
- 最大宽度：360px
- 内边距：12px

可折叠。支持 tab 切换。不允许无限拉宽。不能把主图挤压得太小。

### 4.6 底部上下文栏 Bottom Context Bar

- 高度：36px
- 左右内边距：12px

默认轻量。不作为主要信息区。仅在需要时显示。

## 5. 栅格与间距系统

8pt 栅格系统：

- 4：微调、图标与文字极小间距
- 8：基础控件间距
- 12：模块内部紧凑间距
- 16：标准容器内边距
- 24：模块间距
- 32：页面大区块间距

## 6. 色彩系统

### 6.1 颜色 Token

- bg.canvas / bg.surface / bg.surfaceHover / bg.surfaceActive
- border.subtle / border.default / border.strong
- text.primary / text.secondary / text.tertiary
- icon.primary / icon.secondary
- accent.primary / accent.soft
- state.up / state.down / state.warning / state.info / state.success

### 6.2 深色主题方向

- bg.canvas: 接近 #0f1116
- bg.surface: 比背景略亮一层
- border.subtle: 低对比灰线
- text.primary: 高亮灰白
- text.secondary: 中灰
- text.tertiary: 低对比浅灰
- accent.primary: 冷色单强调
- state.up: 上涨色
- state.down: 下跌色

### 6.3 禁止事项

不要纯黑背景、不要荧光色大面积使用、不要多个主强调色、不要紫蓝粉渐变做主体背景、不要按钮颜色过于抢眼。

## 7. 字体系统

### 7.1 字号体系

- 24：页面主标题（少用）
- 20：一级模块标题
- 16：二级标题
- 14：正文 / 按钮 / Tab / 表单
- 13：表格正文 / 列表数据
- 12：辅助说明 / 标签 / 坐标轴
- 11：极弱说明

### 7.2 字重体系

- 600：关键标题、关键数字
- 500：按钮文字、tab、次级标题
- 400：正文、表格内容

### 7.3 数字规范

数字列统一右对齐、涨跌幅统一保留相同位数、成交额/成交量单位统一、正负号显示统一。

## 8. 圆角、边框、阴影

### 8.1 圆角规范

- 小按钮 / 小输入框：6px
- 卡片 / 面板：8px
- 弹层 / 抽屉：10px
- 大容器：12px

禁止超大圆角胶囊化风格。

### 8.2 边框规范

优先使用 1px 边框。主要用于模块分区。避免边框强度不统一。

### 8.3 阴影规范

常规面板可不加阴影。弹层可使用轻微阴影。禁止厚重/发光/营销页式阴影。

## 9. 图标系统

统一使用简洁线性图标。常规 16-18px，侧栏 18-20px，极小辅助 14px。

必须支持状态：default / hover / active / disabled

## 10. 按钮规范

### 10.1 类型

- Primary：当前区域最重要操作
- Secondary：常规操作
- Ghost：工具栏弱操作
- Danger：删除、清空、高风险动作

### 10.2 尺寸

- S：28px
- M：32px
- L：36px

一个局部区域内只允许一个 primary。

## 11. 输入框与搜索框

高度：32px，内边距：12px，圆角：8px。背景清晰但不抢眼，focus 状态明确。

## 12. Tabs 与分段切换

默认低对比，当前选中状态明确。不使用夸张胶囊外形。标签名称短。

## 13. 卡片规范

卡片只是辅助信息容器，不是主界面主角。轻边框、小圆角、低阴影或无阴影。

## 14. 表格与列表规范

### 14.1 原则

高密度、高可扫视性、强对齐、状态明确、字号统一。支持排序、hover、selected。

### 14.2 列对齐

文本列左对齐、数字列右对齐、百分比列右对齐、标签列左对齐。

### 14.3 行高

紧凑模式：36px，标准模式：40px。

### 14.4 行状态

必须支持：default / hover / selected / active / disabled

## 15. 图表区专项规范

图表是核心模块。背景干净、边界清晰、内部 padding 尽量少。

图例放左上角，轻量，小字号。网格线弱化，时间轴/价格轴清晰。

## 16. 右侧信息面板规范

建议 tab 式：自选 / 详情 / 新闻 / 预警。

自选面板：高密度、可排序、当前选中项清楚。
详情面板：只展示摘要，不展示长文。

## 17. 状态系统

所有组件：default / hover / active / selected / focus / disabled / loading / error

语义状态：success / warning / error / info / up / down / neutral

## 18. 动效规范

- hover：100-150ms
- 面板展开收起：160-220ms
- tab 切换：120-180ms
- 抽屉弹出：180-240ms

禁止大幅弹跳、长时间过渡、花哨缩放特效。

## 19. 响应式规范

优先桌面端。最低适配 1280，推荐 1440-1728，支持超宽屏。

缩窄处理优先级：折叠右侧面板 > 收纳顶部次级按钮 > 隐藏底部次级栏 > 左侧栏最小化 > 主图区域最后再缩小。

## 20. 文案规范

短、准、工具化、不空泛、不营销化。

## 21. 禁止事项总表

- 不要做成资讯网站/营销官网风格
- 不要大面积卡片堆叠
- 不要花哨渐变背景
- 不要过重阴影
- 不要多个主按钮抢焦点
- 不要大圆角胶囊化组件泛滥
- 不要让右侧面板挤压主图太多
- 不要让不同页面像不同产品
- 不要图表小说明模块大
- 不要表格/字号/颜色体系混乱
- 不要堆太多无意义说明文字
