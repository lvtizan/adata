# 牛股集中营 v2 — 信息架构升级方案

## 设计目标

从"看数据"升级到"做决策"。交易员看到一只牛股时，脑子里在想三件事：

1. **技术面行不行？** — K 线形态、量价关系、相对强弱
2. **基本面撑不撑得住？** — 营收增速、盈利能力、估值
3. **有没有催化剂？** — 最近有什么消息、公告、政策

现在的页面只覆盖了第 1 点。升级后三点全覆盖，而且信息获取不需要离开页面。

## 各 Tab 详细设计

### Tab 1：图表（默认，已有）

保持现有的三图联动结构：
- 主图 K 线 + 画线工具
- 副图 成交额 + 相对强弱曲线
- 副图 个股 RPS vs 板块 RPS

无需大改，已经很好。

### Tab 2：财务

#### 信息来源
后端接口 `/api/stock/{ts_code}/financials`（已实现）

#### 展示内容

**顶部：4 个核心指标卡片**

```
┌──────────┬──────────┬──────────┬──────────┐
│ 最新营收  │ 最新净利  │ 毛利率   │ ROE      │
│ 128.5亿  │ 18.2亿   │ 32.1%   │ 15.8%    │
│ ▲ +22.3% │ ▲ +18.7% │ +1.2pp  │ +0.5pp   │
│ (同比)    │ (同比)    │ (环比)   │ (环比)   │
└──────────┴──────────┴──────────┴──────────┘
```

**中部：营收 + 净利润趋势图**

用 lightweight-charts 的 HistogramSeries 画最近 8 个季度的柱状图：
- 营收柱状（蓝色）
- 净利润折线（红色，叠加在同一图上）
- 横轴：2024Q1, 2024Q2, ...

**底部：季度明细表格**

| 报告期 | 营收 | 同比 | 净利润 | 同比 | 毛利率 | ROE |
|--------|------|------|--------|------|--------|-----|
| 2025Q3 | 128亿 | +22% | 18亿 | +19% | 32% | 16% |
| ... | | | | | | |

#### 实现要点
- 金额单位：Tushare 返回元，前端换算为"亿"（÷1e8）
- 同比增速：后端已计算 `revenueYoY` / `netIncomeYoY`
- 趋势图高度和 K 线主图一致（420px），保持视觉节奏

### Tab 3：资讯（DeerFlow 驱动）

#### 两种模式

**模式 A：静态展示（无需 DeerFlow）**

在后端新增接口，用 Tushare 的 `news` / `anns` 接口拉取：
- 个股最近 10 条公告
- 所属行业最近新闻

前端直接展示标题列表 + 日期，点击跳转原文。

**模式 B：AI 研究简报（DeerFlow 驱动）**

页面上有一个"生成研究简报"按钮。点击后：
1. 前端调 DeerFlow API（或本地 MCP Server HTTP 模式）
2. DeerFlow 执行 `skill_stock_research.md` 工作流
3. 返回结构化的 Markdown 简报
4. 前端用 `react-markdown` 渲染

简报内容（参见 `deerflow/skill_stock_research.md`）：
- 一句话结论
- 核心财务数据表
- 技术面分析
- 近期催化剂
- 风险提示
- 综合评分

#### 缓存策略
- 研究简报按 `{tsCode}:{date}` 缓存到 localStorage
- 同一天同一只股不重复生成
- 在简报顶部标注生成时间

## 左侧列表增强

### 新增列：状态标签

在股票名称后面加标签：

- **新** — 今天新进入集中营（昨天不在）
- **3D** / **5D** / **10D** — 连续 N 天在集中营中
- **财** — 近 7 天有新的财务公告

#### 实现方式
后端 `bull_camp()` 返回数据时增加：
- `daysInCamp`: 连续在营天数（对比最近 N 天的集中营列表）
- `isNew`: 是否今天新进
- `hasRecentAnnouncement`: 近 7 天是否有公告

### 新增列：迷你趋势

在综合分右边加一列"趋势"，显示最近 5 天的 campScore 变化：
- 用 5 个小圆点或迷你 sparkline 表示
- 颜色表示分数升降

## 信息卡头部增强

现有：名称 + 代码 + 板块 + 3 个快速指标（RPS20、相对强弱、综合分）

增加：
- **状态标签**：新进 / 连续 N 天 / 板块龙头
- **一行摘要**：DeerFlow 生成的一句话评价（缓存后直接读）
- **快速操作**：加入自选 / 生成研究简报 / 查看同板块其他牛股

## 实现优先级

### P0（先做，纯前端 + 已有接口）
1. Tab 栏框架（图表/财务/资讯）
2. 财务 Tab：指标卡片 + 季度表格
3. 左侧列表状态标签（新进/连续天数）

### P1（需要少量后端改动）
4. 财务 Tab：营收趋势迷你图
5. 资讯 Tab 模式 A：公告/新闻列表
6. 左侧列表迷你趋势 sparkline

### P2（需要 DeerFlow 集成）
7. 资讯 Tab 模式 B：AI 研究简报
8. 一句话摘要缓存
9. "生成研究简报"按钮 + 加载状态

## 后端新增接口清单

| 接口 | 用途 | 优先级 |
|------|------|--------|
| `/api/stock/{ts_code}/financials` | 财务数据 | ✅ 已实现 |
| `/api/stock/{ts_code}/announcements` | 个股公告 | P1 |
| `/api/camp/bull-stocks/history` | 集中营历史（计算连续天数） | P0 |
| `/api/deerflow/research` | 触发 DeerFlow 研究 | P2 |

## 技术栈补充

- Tab 切换：React useState，懒加载 Tab 内容
- Markdown 渲染：`react-markdown`（用于 DeerFlow 简报）
- 迷你图：lightweight-charts 或 SVG sparkline
- 数据缓存：前端 `lib/api.js` 已有内存缓存机制，复用即可
